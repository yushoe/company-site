# スカイライン・テクノロジーズ 企業サイト

東京・福岡を拠点に、物流・不動産・自治体向けのシステム開発を行う「スカイライン・テクノロジーズ」の企業サイトです。
ビルドツールやサーバーを使わない、静的な HTML だけで構成しています。

## ページ構成

トップページ(`index.html`)は、次のセクションを縦に並べた1ページ構成です。

- ヒーロー(キャッチコピー・相談ボタン)
- 事業内容
- 自社プロダクト
- 開発の進め方
- 数字で見るスカイライン
- お客様の声
- 会社概要
- お問い合わせ

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | サイト本体。CSS と JavaScript もこのファイルに含まれています |
| `page.html` | `index.html` から `<!doctype>`・`<html>`・`<head>`・`<body>` のタグを除いた本文部分 |

## ブラウザで表示する手順

### ファイルを直接開く

1. Finder で `company-site` フォルダを開きます。
2. `index.html` をダブルクリックすると、既定のブラウザでページが開きます。
   - 別のブラウザで開きたい場合は、`index.html` を右クリックして「このアプリケーションで開く」からブラウザを選びます。

ターミナルからは、次のコマンドでも開けます(macOS)。

```sh
open index.html
```

### ローカルサーバーで開く(任意)

ファイルを直接開いても表示できますが、本番環境に近い状態で確認したい場合は、簡易サーバーを起動します。

```sh
python3 -m http.server 8000
```

起動後、ブラウザで <http://localhost:8000/> を開きます。終了するときはターミナルで `Ctrl + C` を押します。

## 補足

フォントは Google Fonts から読み込んでいます。オフラインの環境では、フォントだけが代替フォントで表示されます。
